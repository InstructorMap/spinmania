# Café Zodíaco Android

Experiencia móvil mágica de cafetería y universo zodiacal, empaquetada como aplicación Android mediante WebView.

## Funciones actuales
- Perfil de los doce signos y bebida astral sugerida.
- Misión diaria para descubrir cinco estrellas.
- Polvo estelar y colección zodiacal guardados localmente.
- Carta conceptual del café.
- Sin cuenta obligatoria, pagos, apuestas ni premios canjeables.

## Compilación
Abrir en Android Studio con JDK 17+ y Android SDK 35. La APK se genera en `app/build/outputs/apk/debug/app-debug.apk`.
GitHub Actions compila y prueba instalación y arranque en un emulador Android 14.

El polvo estelar es una puntuación virtual gratuita, no comprable, no retirable y no canjeable por dinero. La carta es conceptual; todavía no procesa pedidos ni pagos.
