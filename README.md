# SPINMANÍA Android

Proyecto Android independiente con el juego incluido localmente (WebView + HTML/CSS/JS).
No depende de Replit ni de conexión a internet para jugar.

## Abrir y compilar
1. Abrir esta carpeta desde Android Studio.
2. Esperar la sincronización de Gradle.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).

Requisitos: Android Studio reciente, JDK 17+ y Android SDK 35.
El archivo APK se genera en `app/build/outputs/apk/debug/app-debug.apk`.

## Contenido
- Juego 5x3, créditos virtuales gratuitos, combinaciones y premios.
- Bonus Hold & Win simplificado.
- Persistencia local del saldo.
- Interfaz móvil en español.
- Sin apuestas con dinero, depósitos, retiros ni premios canjeables.

Nota: este paquete contiene el proyecto fuente Android listo para compilar; no incluye un APK binario precompilado.
